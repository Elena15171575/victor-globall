1. КАРТА СТРАНИЦ САЙТА (HTML)
------------------------------------------------------------------------
* index.html      — Главная страница портфолио.
* art.html        — Арт-раздел. В самом низу встроена черная кнопка с 
                    красной обводкой и плавно вращающейся розой.
* gallery.html    — Фотогалерея. В самом низу добавлена футуристичная 
                    черная кнопка с ярко-зеленым неоновым ободком.
* collab.html     — Раздел сотрудничества. Содержит 16 интерактивных 
                    больших карточек брендов с эффектом всплытия 
                    и проявляющимися бутонами роз (вид сверху).
* education.html  — Программы обучения. Настроен стильный вертикальный 
                    список курсов с акцентным красным наведением.
* production.html — Страница междисциплинарной лаборатории (Производство).
* about.html      — Информация о Викторе и концепции его творчества.
* contacts.html   — Контактные данные, ссылки на социальные сети и формы.
* cookie.html     — Служебная страница политики безопасности для подвала.
* 404.html        — Кастомная страница ошибки при неверном адресе.

2. СТРУКТУРА СЛУЖЕБНЫХ ПАПОК
------------------------------------------------------------------------
* /css/    — Таблицы стилей (оригинальные файлы Tilda и сетка tilda-grid).
* /js/     — Скрипты для анимации, ленивой загрузки (lazyload) и эффектов.
* /images/ — Папка для всех фотографий и логотипов. 
             Важно: имена файлов загружать строго маленькими латинскими 
             буквами без пробелов (пример: omshanti.jpg, 2.jpg).
* /files/  — Папка для документов, PDF-файлов и публичных оферт.

3. ФИРМЕННАЯ ПАЛИТРА ЦВЕТОВ (CSS CODES)
------------------------------------------------------------------------
* #000000 — Глубокий абсолютно черный цвет (основной фон сайта и кнопок).
* #0b0c0d — Темно-угольный цвет (для мягкого выделения блоков/подложек).
* #ffffff — Чистый белый цвет (для контрастных заголовков и текстов).
* #888888 — Нейтральный серый цвет (для неактивных пунктов меню).
* #555555 — Темно-серый цвет (для мелкого текста копирайта в подвале).
* #e50914 — Фирменный готический ярко-красный (для роз и вспышек меню).
* #ff2e3b — Алый неоновый цвет (для акцентов при наведении мышки).
* #00ff66 — Ярко-зеленый неон (для обводки и свечения кнопки в Галерее).

4. СТИЛИ И ШРИФТЫ САЙТА
------------------------------------------------------------------------
* Основной шрифт проекта: Системный сан-сериф (-apple-system, BlinkMacSystemFont, 
  'Segoe UI', Roboto, Arial, sans-serif) и TildaSans.
* text-transform: uppercase; — команда, делающая все буквы заглавными.
* letter-spacing: 0.15em;    — межбуквенный интервал (разрядка) для премиального вида.
* text-decoration: none;     — скрытие стандартного синего подчеркивания у ссылок.

------------------------------------------------------------------------
5. ШПАРГАЛКА ПО ГЛАВНЫМ HTML-ТЕГАМ ДЛЯ УЧЁБЫ
------------------------------------------------------------------------
* <!DOCTYPE html> — Самая первая строчка. Инструкция для браузера, что сайт на HTML5.
* <html></html>   — Главный контейнер ("дом") для всего кода страницы.
* <head></head>   — Невидимая "голова" сайта. Тут лежат настройки метатегов и стилей.
* <body></body>   — "Тело" сайта. Сюда пишется всё, что человек видит на экране.
* <header></header> — Тег для создания шапки сайта и верхнего меню.
* <footer></footer> — Тег для создания подвала сайта (футера).
* <div></div>     — Универсальный блок-коробка для разделения и верстки дизайна.
* <nav></nav>     — Специальный блок, внутри которого живут навигационные ссылки.
* <a></a>         — Главный тег для ссылок. Параметр href="адрес" указывает путь.
* <h1>, <h2>      — Теги для крупных и важных заголовков текста.
* <p></p>         — Обычный абзац текста.
* <ul></ul>       — Открывает маркированный (точечный) список элементов.
* <li></li>       — Одна отдельная строчка (пункт) внутри списка <ul>.
* <img>           — Одиночный тег для вставки картинок. Путь пишется как src="путь".
* <svg></svg>     — Код векторной графики (используется для наших идеальных роз).
